# 🏢 Enterprise AI Chatbot for Business Automation

## 📌 Project Overview

Enterprise AI Chatbot for Business Automation is an AI-powered web application developed using **Python**, **Streamlit**, and the **Groq Llama 3.3 model**. It helps employees perform everyday business tasks and quickly access company information through a simple chatbot interface.

The application combines AI-powered question answering with business automation features such as leave requests, IT support ticket creation, meeting room booking, and professional email generation.

---

## ✨ Features

* 🤖 AI-powered Company Information Chatbot
* 📝 Leave Request Management
* 💻 IT Support Ticket Generation
* 📅 Meeting Room Booking
* 📧 AI Email Generator
* 🏢 Company Knowledge Base
* 🎨 Simple and User-Friendly Interface

## ⚙️ Installation

### 1. Clone the repository

```bash
git clone https://github.com/your-username/Enterprise_AI_Chatbot.git
```

### 2. Open the project folder

```bash
cd Enterprise_AI_Chatbot
```

### 3. Install the required packages

```bash
pip install -r requirements.txt
```

### 4. Create a `.env` file

```text
GROQ_API_KEY=your_groq_api_key_here
```

---

## ▶️ Run the Application

```bash
python -m streamlit run app.py
```

## 💡 How It Works

The chatbot uses a predefined company knowledge base (`company_data.txt`) together with the Groq Llama 3.3 model to answer employee queries.

Employees can also perform business-related tasks such as:

* Submit leave requests
* Generate IT support tickets
* Book meeting rooms
* Generate professional business emails
